# Meus Projetos com Pandas e Ciencias de Dados
Bem-vindo ao meu portfolio profissional de dados! Aqui estao reunidos tres projetos que desenvolvi para simular cenarios reais do mercado, utilizando Phyton e a biblioteca Pandas para tratamento, analise e visualizacao de dados.
---
## Projeto 1: Global Sales Corp (E-comemerce)
Analise financeira completa do fechamento de vendas mensal de uma empresa.
*  **Habilidades Utilizadas:** Operacoes matematicas em lote, calculo de metricas automaticas (`.sum()` e `.mean()`) e filtragem condicional de produtos de alto valor monetario.
*  **Resultado:** Geracao de tabelas de faturamento limpas e relatorios visuais com graficos de barras para a diretoria.

## Projeto 2: Detetive do streaming (Audiencia)
Analise de engajamento e padroes de consumo de usuarios em plataformas de video.
*  **Habilidades Utilizadas:** Transformacao e tratamento de dados brutos (conversao de minutos para  horas), filtros de maratona de dados de series e midias mais assistidas.
*  **resultado:** geracao de graficos de barras horizontais (`kind="barh"`) para relatorios rapidos de negocios.

## Projeto 3: School System (Boletim Escolar)
Automacao e tratamento de sistemas de notas academicas.
*  **Habilidades Utilizadas:** Tratamento profundo de erros ocultos de bibliotecas (`tracebacks`), gerenciamento de maiusculas/minusculas (*case-sensitive*) e aplicacao de filtros logicos de aprovacao direta (`>= 7.0`).
*  **Resultado:** Listas automatizadas de alunos aprovados e graficos comparativos de medias finais.
---
### tecnologias e ferramentas dominadas:
*  **Phyton:** Estruturas condicionais (`if/else`), loops (`for`), listas e manipulacao de tipos.
*  **Pandas:** Manipulacao de DataFrames, tratamento de valores faltantes (`NaN`) com `.dropna()` e `.fillna()`, e remocao de duplicadas com `.drop_duplicates()`.
*  **Matplotlib:** Geracao de graficos personalizados para suporte em tomadas de decisao.
